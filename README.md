# Student Management System

A complete Student Management System built with Laravel 12.

## Features

* User Registration
* Login with Email or Phone
* Logout
* Forgot Password
* Reset Password
* Change Password
* Google Login
* Student CRUD Operations
* Search Students
* Sorting
* Pagination
* Dashboard
* Middleware
* Soft Deletes

## Technologies Used

* Laravel 12
* PHP
* MySQL
* Bootstrap 5
* Git
* GitHub

## Installation

```bash
git clone https://github.com/shahzade-alam/student-management-system.git

cd student-management-system

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```
